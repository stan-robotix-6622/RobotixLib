# RobotixLib ![star](https://img.shields.io/github/stars/stan-robotix-6622/RobotixLib)
Librairie utilisée par Stan Robotix 6622 pour leurs robots FRC

## Comment utiliser
Copier le fichier `RobotixLib.cpp` dans `src/main/cpp` de ton projet et le fichier `RobotixLib.hpp` dans `src/main/include` de ton projet
